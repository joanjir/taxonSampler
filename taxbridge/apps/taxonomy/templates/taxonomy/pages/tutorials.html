Learn the basics of navigating TaxonSampler and understanding its core workflow.

Steps
1
Access the Taxonomy Browser

From the sidebar, click Taxonomy → Tree to open the interactive taxonomy browser. This displays the complete taxonomic hierarchy imported from COL.

2
Navigate the Tree

Click on any node to expand its children. Use the search bar to find specific taxa by name. The tree supports 26+ taxonomic ranks from Kingdom to Species.

3
View Taxon Details

Click on a species or genus to see its details panel: COL ID, NCBI Tax ID, classification path, and linked genome assemblies (if available).

4
Start Sampling

Select a taxon as your sampling scope and click "Sample this clade" to launch the sampling wizard.

Tip: TaxonSampler only shows species that have at least one genome assembly in NCBI. If a species doesn't appear, it may not have sequenced genomes yet.

Filter genomes by assembly level and quality metrics to build a dataset that meets minimum standards.

Steps
1
Select Your Scope

Navigate to a parent taxon (e.g., Mammalia) and click "Sample this clade" to begin.

2
Set Assembly Level Filter

In the filters panel, select minimum assembly level: Chromosome or Complete Genome for high-quality analyses. Scaffold-level is acceptable for broader surveys.

3
Apply Contig N50 Threshold

Set a minimum Contig N50 (e.g., 1 Mb for mammals). This ensures assemblies have reasonable contiguity.

4
Preview Results

Review the filtered list showing species count, average metrics, and taxonomic distribution before export.

5
Export

Download results as JSON (for programmatic use), TXT (species list), XLSX (full metadata), or Newick (phylogenetic tree).

Pro tip: Use the "Reference genome only" filter to restrict results to NCBI-designated reference genomes, which typically have the highest quality.

Select a fixed number of species per taxonomic grouping to ensure broad evolutionary coverage.

When to Use
  • Comparative genomics across diverse lineages
  • Avoiding overrepresentation of well-studied groups
  • Building training datasets with balanced taxonomic distribution
Steps
1
Select Scope and Enable Diversity Mode

Choose your target clade and activate "Taxonomic diversity mode" in the sampling options.

2
Choose Grouping Rank

Select the rank for grouping: Family (broad coverage), Genus (finer resolution), or Order (very broad).

3
Set Species per Group

Specify how many species to select from each group (e.g., 2 per family). The algorithm picks the best-quality genomes from each group.

4
Apply Optional Quality Filters

Combine with quality thresholds—only species meeting minimum standards will be candidates for selection.

5
Review Distribution

Check the preview showing which groups contributed species and verify coverage is balanced.

Note: Groups with fewer species than requested will contribute all available species. Empty groups (no genomes meeting criteria) are noted in the report.

Rank and select genomes by a weighted quality score to get the best available assemblies.

Contig N50 30% Higher N50 = better contiguity

RefSeq Category 15% Reference > Representative > na
Steps
1
Enable Quality Scoring

In the sampling wizard, select "Rank by quality score" as your selection method.

2
Customize Weights (Optional)

Adjust the weight distribution if your analysis prioritizes specific metrics (e.g., increase N50 weight for structural analyses).

3
Set Target Count

Specify how many top-scoring genomes you need (e.g., "top 50").

4
Export with Scores

The XLSX export includes the computed quality score for each genome, enabling downstream filtering.

Caveat: This strategy may result in taxonomically biased datasets, favoring groups with more sequencing investment (e.g., model organisms).

Maximize phylogenetic breadth by selecting species that span the maximum evolutionary diversity within your target clade.

Algorithm Overview

TaxonSampler uses a greedy algorithm to maximize phylogenetic diversity:

  1. Build a taxonomic distance matrix from the classification hierarchy
  2. Select the species maximizing distance from already-selected species
  3. Repeat until target count is reached
Steps
1
Enable Phylogenetic Diversity Mode

Select "Maximize phylogenetic coverage" in the advanced sampling options.

2
Apply Pre-filters

Set minimum quality thresholds first—the diversity algorithm only considers species meeting these criteria.

3
Set Target Count

Specify how many species you need. Larger counts provide denser coverage but take longer to compute.

4
Review Selection

Inspect the selected species list and verify representation across major lineages.

5
Export as Newick

Download the Newick tree to visualize phylogenetic distribution in tools like FigTree or iTOL.

Performance note: For clades with >10,000 candidate species, computation may take several minutes. Consider applying stricter pre-filters to reduce the candidate pool.

A complete example: selecting high-quality beetle genomes for a comparative genomics study of Coleoptera.

Scenario

You need 100 beetle genomes for a pan-Coleoptera gene family analysis. Requirements:

  • Chromosome-level or complete assemblies only
  • Contig N50 ≥ 500 Kb
  • At least one species per family when possible
  • Annotated genomes preferred
Workflow
1
Navigate to Coleoptera

Open Taxonomy → Tree, search for Coleoptera, and click "Sample this clade".

2
Apply Quality Filters
  • Assembly level: ≥ Chromosome
  • Contig N50: ≥ 500,000 bp
  • Has annotation: Yes (preferred, not required)
3
Enable Taxonomic Diversity

Set grouping to Family with 2 species per family. This ensures broad coverage across beetle families.

4
Set Target to 100

If fewer than 100 species meet criteria, TaxonSampler returns all available.

5
Review and Adjust

Check the preview. If count is too low, relax filters (e.g., Scaffold-level, lower N50). If too high, tighten or reduce species per family.

6
Export as XLSX

Download the full metadata spreadsheet with accessions, quality metrics, and taxonomy for your methods section.

7
Export as Newick

Download the species tree for visualization and to verify phylogenetic distribution.

Reproducibility: Save the sampling configuration as JSON to document your exact criteria for the paper's methods section.
Expected Output

A dataset of ~100 high-quality beetle genomes distributed across 40-50 families, with full metadata for each assembly including accession numbers ready for batch download from NCBI.
